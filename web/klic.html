🔑 Klíč pro GitHub

Ťukni na řádek, rozbalí se. Stránku poslal Flip v upozornění. ← zpět na Chatu

Co je to za klíč

Hlídač běží na GitHubu. Aby ho mohl Flip spouštět a posílat mu data z chaty, potřebuje klíč. GitHub mu říká token (začíná github_pat_). Je to dlouhý řetězec, něco jako heslo, ale jen pro tenhle jeden úkol a jen pro repozitář chata-hlidac.

Stejný klíč je uložený na dvou místech:

  1. Ve Flipu: aplikace Chata brána → Nastavení → „GitHub token“. Bez něj hlídač nespouští.
  2. Na webu v tvém telefonu: pro ⚡ Načíst a ukládání Nastavení.

Klíč má datum platnosti (nejvýš rok). Pak přestane fungovat a je potřeba vyrobit nový. Flip tě na to upozorní 14 a 3 dny předem.

Klíč nikomu neposílej, ani do chatu s Claudem. Vkládá se jen do Flipu a na web.

Výměna klíče – krok za krokem (~5 min)

Nejlíp na počítači, jde to i na telefonu. Stránku GitHubu nezavírej, dokud klíč nevložíš do Flipu i na web. Nový klíč ukáže GitHub jen jednou.

  1. Otevři github.com/settings/personal-access-tokens/new a přihlas se jako KptDundee.
    Kdyby odkaz nešel: vpravo nahoře ikona účtu → Settings → úplně dole vlevo Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: třeba chata Flip 2026-11 (jméno je jen pro tebe).
  3. Expiration: vyber Custom a datum za rok (nebo nejdelší, co nabídne).
  4. Repository access: Only select repositories → vyber KptDundee/chata-hlidac.
  5. Permissions → Repository permissions (u novější podoby stránky tlačítko Add permissions):
    • Actions → Read and write
    • Contents → Read and write
    Metadata (Read-only) se přidá samo. Nic dalšího nezapínej.
  6. Dole Generate token (případně ještě jednou potvrď). Objeví se klíč github_pat_… → ťukni na ikonu kopírovat vedle něj.
  7. Flip: otevři aplikaci Chata brána → ✏️ Upravit nastavení → pole „GitHub token (Actions: Read and write)“ → starý obsah celý smaž, vlož nový → 💾 Uložit.
    Když kopíruješ na počítači: pošli si klíč do Flipu bezpečně (např. sám sobě do poznámky, kterou pak smažeš), ne e-mailem cizím lidem.
  8. Ověř Flip: v aplikaci dej Odeslat teď (nebo počkej ~10 min). V záznamu musí být řádek „Odesláno (GitHub): …“. Do pár minut přijde upozornění „✓ Data zase chodí“.
  9. Web v telefonu: otevři stránku Chata → ⚡ Načíst. Když napíše „Token nefunguje – zadej ho znovu“, nebo ukáže pole „github_pat_…“, vlož tam nový klíč a ulož.
    Když web klíč nechce, je to tím, že u něj chybí Contents: Read and write (krok 5).
  10. Jen jestli máš záložní spouštění na cron-job.org: přihlas se tam → otevři úlohu, která spouští hlídače (adresa api.github.com/…/dispatches) → v hlavičkách (Headers) u Authorization nech Bearer a za mezeru vlož nový klíč → uložit.
  11. Starý klíč smaž (není nutné, jen pořádek): github.com/settings/personal-access-tokens → starý klíč → Delete.

Hotovo, když: ve Flipu je „Odesláno (GitHub)“, přišlo „✓ Data zase chodí“ a web po ⚡ Načíst ukáže čerstvá data.

Hlídač neběží, ale klíč je v pořádku (výpadek)

Flip se nedostal na GitHub. V upozornění je důvod:

  1. „nenajde adresu GitHubu (internet / DNS)“: na chatě vypadl internet, nebo router neumí přeložit adresu. Většinou to samo přejde. Když to trvá přes hodinu: restartuj router.
  2. „GitHub neodpovídá“ / „výpadek GitHubu (5xx)“: problém je na straně GitHubu. Nic nedělej, přejde to. Stav je na githubstatus.com.
  3. „GitHub odmítá klíč“: viz Výměna klíče.

Data se neztratí. Flip je mezitím ukládá a pošle, až to půjde, a díry v grafech se doplní. Dokud hlídač neběží, nechodí jeho upozornění (baterie, River, noc). Flip proto zkouší odeslat každé 2 min a po obnovení pošle „✓ Data zase chodí“.
